### Project Description - Summary:

This project aims to provide the Filipino fisherfolk(or more generally those who rely on finishing as their source of income) with a reliable system that allows them to monitor, evaluate and determine the water quality in specific areas by analyzing key parameters such as PH levels, temperature, turbidity and more. Through all these measurements, the system can automatically assess whether a location is safe and suitable for fishing, or if a warning needs to be issued. 

Advising fishermen to stay out of the water if conditions are hazardous helps protect both their livelihoods and personal safety.

### Project Description - Features:

- This project would primarily help fisherfolk around the world to determine the safe fishing locations by analyzing key measurements related to the location.

### Project Description - Summary:

This project aims to provide the Filipino fisherfolk(or more generally those who rely on fishing as their source of income) with a reliable system that allows them to monitor, evaluate and determine the water quality in specific areas by analyzing key parameters such as PH levels, temperature, turbidity and more. Through all these measurements, the system can automatically assess whether a location is safe and suitable for fishing, or if a warning needs to be issued. 

Advising fishermen to stay out of the water if conditions are hazardous helps protect both their livelihoods and personal safety.

### Project Description - Features:

- This project would primarily help fisherfolk around the world to determine the safe fishing locations by analyzing key measurements related to the location.

- System components: The code will ask the player for the location and analyzes the current state as the class; location where it contains a relationship HAS A with class; info in which the fisherfolk can input to analyze as this class info has the attributes PH level, Temperature, Turbidity, Dissolved Oxygen, and Fishing Pressure. After determining whether that same class has the method, the system runs a constant safety check to tell the fishermen if it is safe.
- Features: The system analyzes whether the location is safe based on the information given (PH levels, Temperature, Turbidity, Dissolved Oxygen, and Fishing Pressure) based of a specific chosen location. 
- Expected outputs: Gives the information about the location. Gives a determined answer (SAFE/NOT SAFE) based on the provided information.
